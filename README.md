# LeetCode Solved Problems

A running log of LeetCode problems solved in Python, as part of consistent DSA practice — building toward stronger fundamentals for interviews and GATE CS 2027 prep.

## Structure

Each problem lives in its own folder, named as:

```
NNNN-problem-slug/
├── solution.py
└── README.md   (problem notes, complexity, approach)
```

Where `NNNN` is the LeetCode problem number, zero-padded (e.g. `0461-hamming-distance`).

## Topics covered so far

- Arrays & Hashing
- Binary Search
- Two Pointers
- Bit Manipulation
- Sorting

## Approach

Solutions favor clarity and correct time/space complexity over cleverness. Each folder generally includes:

- The problem statement (brief)
- The approach / intuition
- Time and space complexity
- Edge cases considered
